Noteworthy changes in release 0.2.0

* Self-contained dom0 RPM and VM theme builder

  The RPM installs the management tool and dracut module. Completed themes
  are generated in a VM and applied in dom0; later dracut builds need no VM.
  Settings and image-generation dependencies stay outside dom0. apply and
  remove replace install and uninstall; package removal restores stock images.

* Preview and builder settings

  --preview opens a PNG or prints its saved path. screens and output are
  settings. decoy_amplitude defaults to 0.3; zero replaces display = highpass.
  The enabled setting and dom0 configuration file are removed.

Migration from 0.1.x: copy /etc/qubes-plymouth-scramble.conf into the builder
before running the old sudo qubes-plymouth-scramble uninstall, which deletes it.
Use that file as ~/.config/qubes-plymouth-scramble.conf in the builder, remove
enabled, set screens, and replace display = highpass with display = hybrid and
decoy_amplitude = 0. Install the RPM, generate a theme in the VM and apply it in dom0.

Noteworthy changes in release 0.1.3

* Digit size and digit panel

  size scales the digits under the keys; the shipped settings use 1.5,
  without the line it stays 1. Key caps keep their size. Masked digits lie
  on one grey panel; panel = no keeps separate tiles. The cut-off and the
  estimated safety distance are those of size 1.

* Text digits where masked digits cannot be shown

  A screen without a reported size, or too coarse for the digit size or the
  cut-off (for example a large monitor at Plymouth's simpledrm scale 2), gets
  text digits instead of stopping the install; install names it.

Noteworthy changes in release 0.1.2

* Masked digits by default

  display defaults to hybrid, the IllusionPIN keypad; display = text keeps
  plain digits. Settings that leave display unset switch to hybrid with the
  next install. Letters or colours in [digits] need display = text.

Noteworthy changes in release 0.1.1

* Only the Plymouth prompt is scrambled

  The text console prompt, used when Plymouth is disabled on the kernel
  command line, keeps standard digits; console scrambling and the console
  letter hint are gone. Delete the console line from
  /etc/qubes-plymouth-scramble.conf before running install; install names it
  otherwise and changes nothing.

* Masked digits

  display = highpass, hybrid or white draws the digits as images after the
  IllusionPIN paper (arXiv 1708.06508): readable up close, fading with
  distance. install makes them in dom0 for the connected screens with the
  stock numpy and Pillow. text stays the default.

* The keypad follows the F1 message

  After F1 the Caps Lock note no longer touches the stock message that
  replaces the password field.

Noteworthy changes in release 0.1.0

* First public release

  Scrambled digit keys for the Qubes OS R4.3 disk password prompt: a dracut
  module writes a new XKB digit layout into the initramfs on every boot, and a
  keypad overlay for the stock qubes-dark Plymouth theme shows the mapping.
  install and uninstall list every change and ask first; uninstall rebuilds the
  initramfs the way kernel-install does.
